# MyToDo

바이브코딩 입문용 **일정·할 일** 정적 웹앱입니다. **Samsung One UI** 개발자 문서의 구조·색·테마 개념을 참고해 스타일을 잡았고, 동작은 **바닐라 JavaScript**(`script.js`)만 사용합니다. **외부 라이브러리·빌드 도구 없음.**

## 기술 스택

- **HTML5** — 시맨틱 마크업, 접근성(`aria-*`, 스크린리더용 라벨)
- **CSS3** — 디자인 토큰(`:root` 변수), `prefers-color-scheme` + `data-theme` 수동 테마, 반응형(단일 열)
- **JavaScript** — `const` / `let`, 배열 상태로 할 일 관리 후 DOM 렌더

## 주요 기능

| 기능 | 설명 |
| ---- | ---- |
| **추가** | 하단 고정 입력창에서 제목 입력 후 **`+`** 로 추가. 마감은 **달력 아이콘**으로 펼쳐 `datetime-local` 선택(선택 사항). |
| **완료** | 체크박스로 완료/미완료, 목록·통계·필터 반영 |
| **삭제** | 행마다 삭제 버튼 |
| **필터** | 전체 / 진행 중 / 완료 |
| **완료 비우기** | 완료된 항목만 일괄 삭제 |
| **제목 편집** | 제목 **더블클릭** → 입력 후 Enter 또는 포커스 해제(Esc 취소) |
| **마감** | ISO 문자열로 저장, 마감 임박·지남 시 행 스타일 갱신, 마감 순 정렬 |
| **통계** | 제목 바로 아래 **가로 3열**(전체·완료·진행 중). 숫자 크게·라벨 작게. 완료 수는 **밝은 그린**(`--stat-done-metric`). |
| **테마** | 라이트/다크, 아이콘(해/달). `localStorage` 키 `mytodo-theme` |
| **저장** | 할 일 배열 JSON → `localStorage` 키 `mytodo-items-v1` |
| **DOM 흐름 패널**(학습용) | 우하단 **「DOM 흐름」** 토글. 추가·삭제·체크·필터 시 이벤트→함수→DOM 흐름을 최근 5건까지 표시(`script.js`에서 주입). |

## 아키텍처 (`script.js`)

- **`todos` 배열**이 단일 소스(SSOT). 추가·삭제·체크·편집·비우기 시 배열을 바꾼 뒤 `renderFullList` / `paintChrome` / `persistTodos` 등으로 DOM·저장을 맞춥니다.
- 통계 숫자는 **DOM이 아니라 배열**에서 `computeStats`로 계산합니다.

## UI 레이아웃

- **모든 뷰포트 단일 열** — 예전 1024px 이상 2열 그리드는 사용하지 않습니다.
- **상단**: 테마 버튼 → 제목 → 통계 3열 → 짧은 안내 문구.
- **본문**: 필터·목록(포커스 블록).
- **하단 고정**: 메신저형 **입력 독**(달력 아이콘 · 텍스트 필드 · `+` 제출). 본문에는 `padding-bottom`으로 독에 가리지 않게 여백을 둡니다.
- **푸터**: 본문 하단에 크레딧(`Made by JJorifong`).

## 반응형(요약)

`--max-app-width`, `--app-pad-x`, `--viewport-pad-x` 등 토큰만 단계적으로 키워 **모바일·태블릿·데스크톱**에서 같은 한 열 경험을 유지합니다. 상세 값은 `style.css` 미디어쿼리를 참고하세요.

## 파일

| 파일 | 역할 |
| ---- | ---- |
| `index.html` | 마크업(통계·목록·하단 독·푸터), `id`로 스크립트와 연결 |
| `style.css` | 토큰, 테마, 단일 열·통계·입력 독·목록 스타일 |
| `script.js` | 상태, 렌더, 테마, 저장소, DOM 흐름 패널 |
| `README.md` | 본 문서 |

## 실행 방법

1. `index.html`을 브라우저로 직접 열거나, **Live Server** 등으로 같은 폴더를 서빙합니다.
2. `index.html`, `style.css`, `script.js`는 **한 디렉터리**에 두어야 합니다.
