# MyToDo

바이브코딩 입문자를 위해 만든 일정·할 일 웹앱이에요.  
`JJorifong`이 만들었고, 외부 라이브러리 없이 `HTML`, `CSS`, `JavaScript`만으로 동작합니다.

## 미리보기

화면은 한 열로 깔끔하게 구성되어 있어요.  
위쪽에는 테마 버튼·제목·통계가 있고, 가운데에서 목록을 관리해요.  
아래 고정 입력창에서 새 할 일을 바로 추가할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| ---- | ---- |
| **추가** | 아래 입력창에 제목을 넣고 **`+`** 를 누르면 추가해요. 마감일은 달력 아이콘을 눌러 고를 수 있어요(선택). |
| **완료** | 체크박스로 완료/미완료를 바꾸면 목록, 통계, 필터가 함께 업데이트됩니다. |
| **삭제** | 항목마다 삭제 버튼이 있어요. |
| **필터** | 전체 / 진행 중 / 완료만 골라서 볼 수 있어요. |
| **완료 비우기** | 완료된 항목만 한 번에 지울 수 있어요. |
| **제목 편집** | 제목을 더블클릭해 수정하고, Enter로 저장하거나 Esc로 취소해요. |
| **마감** | 날짜와 시간을 함께 저장하고, 임박/지남 상태를 화면에 표시해요. 마감이 빠른 순서로 정렬됩니다. |
| **통계** | 제목 아래 3칸(전체·완료·진행 중)으로 개수를 보여줘요. 완료 수는 밝은 초록(`--stat-done-metric`)으로 강조됩니다. |
| **테마** | 라이트/다크 모드를 바꿀 수 있고, 선택한 테마는 `localStorage`의 `mytodo-theme`에 저장돼요. |
| **저장** | 할 일 목록은 JSON(텍스트 데이터 형식)으로 `localStorage`의 `mytodo-items-v1`에 저장돼요. |
| **DOM 흐름 패널**(학습용) | 오른쪽 아래 **DOM 흐름** 버튼으로 열고, 추가/삭제/체크/필터 때 어떤 순서로 화면이 바뀌는지 최근 5건까지 볼 수 있어요. |

## 실행하기

1. `index.html`을 브라우저에서 바로 열거나, **Live Server** 같은 도구로 같은 폴더를 실행합니다.
2. `index.html`, `style.css`, `script.js` 파일은 꼭 **같은 폴더**에 둬야 해요.

## 파일 구성 보기

| 파일 | 역할 |
| ---- | ---- |
| `index.html` | 화면 뼈대(통계, 목록, 하단 입력창, 푸터)를 담고, `id`로 스크립트와 연결해요. |
| `style.css` | 색상·여백 같은 값(디자인 토큰), 테마, 단일 열 레이아웃, 목록 스타일을 담당합니다. |
| `script.js` | 앱의 모든 동작(추가/삭제/완료/필터/저장/테마/DOM 흐름 패널)을 담당하는 JavaScript 파일이에요. |
| `README.md` | 지금 보고 있는 안내 문서입니다. |

## 과제 기준 확인하기

이 프로젝트는 아래 두 가지 과제 기준을 충족하도록 작성됐습니다.

| 기준 | 반영 내용 |
| --- | --- |
| 변수명 명확화 + 함수 최소 단위 분리 | `script.js` 전반의 축약 변수명을 의미 있는 이름으로 바꾸고, `boot()` 내부 인라인 콜백을 개별 핸들러 함수로 분리 |
| 새로고침 후 데이터 유지 (`localStorage`) | 할 일은 `mytodo-items-v1`, 테마는 `mytodo-theme` 키로 저장/복원되어 새로고침 후에도 상태 유지 |

## 코드 구조 가볍게 보기 (궁금한 분만)

- 앱 데이터는 `todos` 배열 한 곳에서만 관리해요(SSOT: 데이터를 한 곳에서만 관리하는 방식).
- 추가/삭제/완료/편집 후에는 `renderFullList`, `paintChrome`, `persistTodos`로 화면과 저장 상태를 맞춥니다.
- 통계는 화면 값을 직접 세지 않고 `computeStats`로 배열에서 다시 계산해요.
- `boot()`는 이벤트 연결 중심이고, 실제 동작은 작은 핸들러 함수로 나눠 읽기 쉽게 만들었습니다.
- 화면은 모바일·태블릿·데스크톱 모두 한 열 레이아웃이며, 상단(테마·제목·통계) / 본문(필터·목록) / 하단 고정 입력창 / 푸터 구조입니다.
- `style.css`는 변수(색상·여백 같은 값을 미리 정의한 것)를 단계적으로 조정해 기기 크기가 달라도 비슷한 사용감을 유지해요.
